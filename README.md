# Drawing Game

 - Users are presented with a target image (likely simple black and white traces maybe generated with AI through code)
 - 30 seconds to recreate the image
 - User-drawing graded based on similarity with original and given score 0-100%
 - 5 rounds
 - Take average score of 5 rounds to get the overall score
